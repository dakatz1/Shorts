# Workout b-roll

Drop vertical (or at least tall) workout clips in here. The pipeline crops them
to the bottom panel, loops them to cover the narration, and strips their audio.

**Naming matters.** Selection prefers clips whose filename mentions the exercise
in the script, so this:

```
squats-01.mp4
squats-02.mp4
pushups-gym-01.mp4
deadlifts-closeup.mp4
calves-01.mp4
```

gets you topical pairing for free. Anything unmatched is still eligible.

Supported: `.mp4` `.mov` `.m4v` `.webm` `.mkv`. 10-30 seconds each is plenty —
clips are looped as needed.

If this folder is empty the pipeline synthesises an obvious placeholder so a
render still completes. Don't publish that.

## Where footage comes from

**You are responsible for having the right to use every clip in here.** Reusing
someone's gym footage without a licence is copyright infringement, and YouTube's
Content ID will find it. Reasonable sources:

- Footage you shot yourself.
- Stock libraries under a licence that permits monetised social video (Pexels
  and Pixabay are free and permissive; Artgrid, Envato and Storyblocks are paid).
- Clips you commissioned.

Note that "free to use" is not the same as "free to monetise" — check the actual
licence. Nothing in this folder is committed to git.

# Caption font

Optional. Drop a `.ttf` here named `caption.ttf` and it will be used for the
captions and the hook.

If there isn't one, the pipeline falls back to a system font (DejaVu Sans Bold,
Liberation Sans Bold, or Arial Bold depending on your OS), which works but looks
generic.

What reads well on Shorts: a heavy, wide sans with tight spacing. Montserrat
ExtraBold, Poppins Bold, Anton, and Bebas Neue are all free on Google Fonts and
all look right for this format.

Font files are gitignored — fonts have their own licences and most shouldn't be
redistributed in a repo.
